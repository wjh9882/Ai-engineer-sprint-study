# 📖 AI 엔지니어 실무 용어 사전 (AI Field Glossary)

> **프로덕션(Production) 관점에서 집요하게 파고드는 AI 엔지니어링 기술/비즈니스 용어 아카이브입니다.**  
> 단순히 사전적 정의를 나열하는 것에 그치지 않고, **"이 기술이 현업 실무 환경에서 왜 쓰이는지"**, **"어떤 비즈니스 임팩트와 트레이드오프(Trade-off)가 있는지"** 엔지니어의 시각으로 분석하고 기록합니다.

---

## 🚀 Core Glossary

### 🛠️ MLOps (Machine Learning Operations)
- **Concept:** AI 모델의 데이터 수집, 학습, 배포, 모니터링, 재학습 과정을 자동화하고 안정적으로 운영하는 체계.
- **Field Insight:** 주피터 노트북에서 모델을 잘 만드는 것을 넘어, 실제 유저가 사용하는 서비스 프로덕션 환경에서 AI가 에러 없이 안정적으로 돌아가도록 파이프라인을 구축하는 실무의 핵심 영역입니다.

### ⚖️ 트레이드오프 (Trade-off)
- **Concept:** 하나를 얻으면 다른 하나를 희생해야 하는 유기적인 저울질 관계.
- **Field Insight:** 모델의 정확도(Accuracy)를 올리면 모델이 무거워져 속도(Latency)가 느려지고 서버 비용이 치솟습니다. 현업 엔지니어는 완벽한 신선놀음 모델을 찾는 게 아니라, 비즈니스 요구사항과 비용 타협점 사이에서 최적의 아키처를 결정하는 역할을 합니다.

### 🔍 RAG (Retrieval-Augmented Generation, 검색 증강 생성)
- **Concept:** 외부 데이터베이스에서 관련 정보를 실시간으로 검색해 모델에게 참고 자료로 제공한 뒤 답변을 생성하게 하는 아키텍처.
- **Field Insight:** 모델을 무겁고 비싸게 새로 파인튜닝(Fine-tuning)시키지 않고도 최신 정보나 사내 보안 문서를 기반으로 정확한 답변을 유도할 수 있어, 현재 실무 프로덕션 환경에서 ROI(투자 대비 효율)가 가장 높은 LLM 아키처 중 하나입니다.

### 🧪 A/B 테스트 (A/B Testing)
- **Concept:** 기존 시스템(A안)과 새로운 AI 모델(B안)에 유저 트래픽을 쪼개어 정량적으로 성능을 비교하는 실험 기법.
- **Field Insight:** AI 엔지니어가 자신의 모델이 실제로 매출을 올렸거나 업무 효율을 개선했음을 증명하여, 정량적인 비즈니스 임팩트(KPI)를 인정받기 위한 가장 확실한 무기이자 실무 검증 절차입니다.

### 🧪 PoC (Proof of Concept, 개념 검증)
- **Concept:** 새로운 기술이나 모델을 실제 도입하기 전에 기술적 실현 가능성과 비즈니스 효용성을 빠르게 검증하는 단계.
- **Field Insight:** 거대한 비용을 들이기 전, 최소한의 리소스로 프로토타입을 빌드하여 아이디어를 검증하는 과정입니다. 현업의 수많은 AI 프로젝트가 이 PoC 단계의 가치 증명 실패로 드랍되기도 합니다.
